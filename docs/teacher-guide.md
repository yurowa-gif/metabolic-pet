# 대사 펫 교사용 안내

생명과학 I "사람의 물질대사" 단원, 대사성 질환 차시용 게임. 학생 스마트폰 브라우저에서 1차시(15~20분) 안에 한 판이 끝난다.

## 수업 흐름 (예시, 50분)
1. 도입 5분: 검진표를 본 적 있는지, 공복혈당·혈압·LDL이 무엇인지 묻기.
2. 플레이 15분: 각자 한 판. 20일 × 45초. 5일마다 검진 팝업을 읽고 넘어가게 한다.
3. 결과 공유 10분: 결과 화면 캡처 제출. "가장 많이 기준을 넘긴 요인"과 "전단계/발병 일차"를 모둠별로 비교.
4. 정리 15분: 퀴즈 4문항 해설, 전단계(가역)와 발병 후(약 + 식단 병행)의 차이, 실제 시간 척도는 수년이라는 점 강조.

## 조작
- 하루 = 아침·점심·저녁·간식 4번 선택 + 활동 1번. 45초가 지나면 남은 끼니는 "거르기"로 처리된다.
- 음식 카드의 %는 식품 라벨과 같은 "1일 영양성분 기준치 대비 비율"이다(당류 100 g, 나트륨 2,000 mg, 포화지방 15 g, 식이섬유 25 g).
- 발병 후에만 약 카드가 보인다. 약은 그날 수치만 내리므로 식단을 바꾸지 않으면 회복되지 않는다.
- 저장은 브라우저 localStorage. 사생활 모드에서는 저장이 안 된다는 안내가 뜬다.

## 판정 기준(원문은 docs/evidence.md)
| 지표 | 전단계 | 발병 | 출처 |
|---|---|---|---|
| 공복혈당 | 100–125 mg/dL | ≥126 | 대한당뇨병학회 2023 |
| 혈압 | 120–139 / 80–89 | ≥140 또는 ≥90 | 대한고혈압학회 2022 표 1 |
| LDL | 130–159 mg/dL | ≥160 | 한국지질·동맥경화학회 2022 표 2-1 |

## 교육용 가속 모델임을 반드시 말해 주세요
- 실제 질환은 수년에 걸쳐 진행된다. 게임은 20일로 압축했고 효과의 방향·순서·가역성만 근거를 따른다.
- 지표 변화 계수는 문헌값이 아니라 수업 길이에 맞춘 보정값이다(`src/data/config.ts`, `docs/evidence.md` §5).
- 의료 조언이 아니다. 학생 본인의 검진 수치 해석에 쓰지 않는다.

## 난이도·내용 조정
- 계수: `src/data/config.ts` (RISE, RELAX, STAGE_DAYS, DAY_MS). 바꾼 뒤 `npm test`로 시나리오 테스트가 통과하는지 확인.
- 음식 카드: `src/data/foods.json`. K-FIND(https://various.foodsafetykorea.go.kr/nutrient/)에서 100 g당 값과 1인분을 가져와 추가.
- 퀴즈: `src/data/quiz.ts`.
- 기준 열량: 시작 화면에서 남 2,700 / 여 2,000 kcal(2025 한국인 영양소 섭취기준 15–18세).

## 배포
```bash
npm install
npm run build
```
`dist/`를 GitHub Pages 등 정적 호스팅에 올리거나, 교실 와이파이에서 `npm run preview -- --host`로 띄운 주소를 학생에게 공유.

## 교육과정 대조(교사 확인 필요)
2015 개정 생명과학Ⅰ "사람의 물질대사" 학습 요소에 대사성 질환이 포함되며, "물질대사와 관련 있는 질병을 조사하고 예방을 위한 올바른 생활 습관에 대해 토의"하는 활동이 있다(교육부 고시 제2015-74호 별책 9, 2차 자료로 확인). 성취기준 번호는 원문과 대조해 주세요.
