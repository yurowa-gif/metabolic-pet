게임의 모든 임상 기준값·식이 기준·음식 영양값과 모델 가정의 출처를 기록한다. 확인일은 모두 **2026-10-20**이며, 확인 방법은 "원문 PDF 텍스트 변환" 또는 "공식 DB 조회"로 적었다. 발췌 텍스트는 `artifacts/runs/2026-10-20-evidence/text/`에, 영양 DB 원본 응답은 `artifacts/runs/2026-10-20-evidence/kfind/`에 있다.

> 이 게임은 **교육용 가속 모델**이다. 실제로 수년에 걸쳐 진행되는 대사성 질환을 게임 20일로 압축했다. 효과의 **방향·순서·가역성**은 아래 근거를 따르되, **속도**는 수업 시간에 맞춰 보정했다. 의료 조언이 아니며 개인의 진단·치료에 사용할 수 없다.

### 1.1 당뇨병·당뇨병전단계

- 발췌: `text/kda2023_diagnosis_quote.txt`
- 기준:

| 항목 | 당뇨병전단계 | 당뇨병 |
|---|---|---|
| 공복혈장포도당 | 100–125 mg/dL (공복혈당장애) | ≥126 mg/dL |

- 게임 반영: 공복혈당만 사용. 전단계 100–125, 발병 ≥126. 같은 문서의 생활습관 권고(체중 5% 이상 감량 시 인슐린 감수성·혈당 개선, 탄수화물 섭취 감소가 혈당 개선에 효과적, 유산소운동 주 150분 이상, 청소년 2형당뇨병 증가·비만과 연관)를 인과 모델에 반영.

### 1.2 혈압 분류
- 출처: 대한고혈압학회, **2022 고혈압 진료지침** 표 1 "혈압의 분류". 확인 자료: 약학정보원 팜리뷰 Trend Focus 「국내 고혈압 진료지침(2022년)」(신나영) p.2. URL: https://common.health.kr/shared/healthkr/pharmreview/팜리뷰_Trend%20Focus%20국내고혈압진료지침(2022년)_최종본.pdf ; 원 지침 https://www.koreanhypertension.org/reference/guide?mode=read&idno=10081
- 발췌: `text/ksh2022_bp_classification_quote.txt`

| 분류 | 수축기(mmHg) | | 이완기(mmHg) |
|---|---|---|---|
| 정상 혈압 | <120 | 그리고 | <80 |
| 주의 혈압 | 120–129 | 그리고 | <80 |
| 고혈압 전단계 | 130–139 | 또는 | 80–89 |
| 고혈압 1기 | 140–159 | 또는 | 90–99 |
| 고혈압 2기 | ≥160 | 또는 | ≥100 |

- 게임 반영: 전단계 = "주의 혈압 + 고혈압 전단계"(120/80 이상 140/90 미만), 발병 = 1기 이상(≥140 또는 ≥90). 나트륨(소금) 과다 섭취가 혈압 상승 요인이라는 점은 같은 지침의 저항성 고혈압 원인 서술("과도한 소금 섭취")로 뒷받침.
- 상태: **원문 표 확인(2차 요약본 경유)**.

- 게임 반영: LDL 전단계 = 경계(130–159), 발병 = 높음 이상(≥160).
- 식사·생활 권고(같은 지침 Chapter 3, 발췌 `text/ksola2022_diet_recommendations.txt`, `ksola2022_satfat.txt`, `ksola2022_carb_sugar.txt`, `ksola2022_energy.txt`):

  - 에너지 과다 → 간세포 콜레스테롤 합성 촉진 → 총콜레스테롤 상승; 체중 5–10% 감량 시 지질 개선; 지방은 2020 KDRIs 기준 에너지의 15–30%
- 상태: **원문 확인**.

## 3. 음식 영양값
- 출처: 식품의약품안전처 **식품영양성분 데이터베이스 K-FIND** https://various.foodsafetykorea.go.kr/nutrient/ (음식 DB·가공식품 DB·원재료성식품 DB). 조회 방법: 공개 목록 API `listJson.do` + 상세 페이지 `detail.do?searchFoodCd=…`. 원본 응답 `kfind/kfind_details_2026-10-20.jsonl`, 조회 스크립트는 스크래치패드 `tools/kfind.js`(프로젝트 미포함).
- 데이터 파일: `src/data/foods.json` (100 g당 값 + 1인분 g). 1인분은 DB의 "총 내용량"을 썼고, DB에 없는 가공식품·원재료는 가정을 `servingBasis`에 명시(콜라 250 mL, 우유 200 mL, 사과 150 g, 바나나 100 g, 아몬드 20 g, 달걀 1개 50 g).
- 선택 원칙: 품목대표(제조사 없음) 항목만 사용. 급식용(D6xx) 대신 가정식(D1xx)·외식(D3xx·D4xx)을 우선.
- 알려진 한계: 음식 DB 일부 항목의 총 내용량이 mL로 표기됨(피자 210 mL, 고등어구이 170 mL). 밀도 1로 간주했다. 라면은 국물 포함 550 g 1인분 기준이라 나트륨 1,557 mg으로, 봉지 라벨값(제품별 1,300–1,900 mg)과 같은 범위.

## 4. 인과 모델 (교과 범위의 단순화)
생명과학 I "사람의 물질대사" 단원(학습 요소: 물질대사, 기관계의 통합작용, 세포 호흡, ATP, 노폐물의 배설 과정, **대사성 질환**; "물질대사와 관련 있는 질병을 조사하고, 대사성 질환을 예방하기 위한 올바른 생활 습관에 대해 토의") 범위로 제한한다. 교육과정 원문: 교육부 고시 제2015-74호 [별책 9] 과학과 교육과정(https://ceri.knue.ac.kr/pds/2015_05_science.pdf). 성취기준 번호는 2차 자료(나무위키 요약)로만 확인했으므로 교사가 원문과 대조할 것.

## 5. 모델 가정 (근거가 아닌 게임 보정)
- 1일 = 45초, 한 판 = 20일. 지표 기준 초과 **3일 연속 → 전단계**, **5일 연속 → 발병**. 실제 질환의 시간 척도와 무관한 수업용 압축.
- 보정 계수(`src/data/config.ts`): 하루 합계가 기준(나트륨 2,300 mg, 당류 10%E, 포화지방 8%E, 에너지 EER×0.5)을 넘는 비율에 비례해 지표가 오르고, 기준 이하면 기준값 쪽으로 하루 8% 회복한다. 시나리오 테스트(`src/sim/scenarios.test.ts`)로 고정한 결과: 가당음료 위주 식단은 4일째 전단계·7일째 당뇨병 범위, 고나트륨 식단은 8일째 고혈압 1기, 고포화지방 식단은 8일째 LDL 높음, 균형 식단은 20일 내내 정상. 수치 자체는 문헌값이 아니다.
- 당류 한계로 총당류 20%E 대신 **첨가당 10%E**를 쓴 이유: 게임 음식 중 당류의 주된 급원이 가당음료이고, 2025 KDRIs가 첨가당을 10%E 이내로, 가당음료 섭취를 줄이도록 권고하기 때문. 과일의 당류도 같은 비율로 계산되므로 과일을 많이 먹으면 보수적으로 평가된다(식이섬유 완화 계수로 일부 상쇄).
- 에너지 대표 비율 0.5: 게임의 하루 4회 선택(DB 1인분)이 실제 하루 섭취의 절반을 대표한다고 가정(남 1,350 / 여 1,000 kcal). 음료·군것질 등 미모델 섭취를 보정하기 위한 장치이며, 3끼만으로는 어떤 조합도 에너지필요추정량에 닿지 않는다는 것을 구현 중 확인했다.
- 2개 이상 질환 동시 발병 → "입원" 엔딩은 합병증 위험 증가를 상징하는 게임 장치이며 임상 규칙이 아니다.
- 체중은 kg 변화량만 표시한다. 청소년 BMI 판정(성장도표 백분위)은 범위에서 제외했다.
